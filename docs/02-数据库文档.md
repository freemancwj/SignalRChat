# CXIM 数据库文档

## 1. 概述

- ORM：Entity Framework Core 8，代码优先（Code First）
- 支持三种数据库，通过 `appsettings.json` 的 `Database:Provider` 切换：
  - `Sqlite`（默认）
  - `SqlServer`（已适配 2008 R2，`UseCompatibilityLevel(100)`；高版本可移除该配置）
  - `MySql`（utf8mb4，Pomelo 驱动）
- **首次启动自动建库建表**（`EnsureCreated`）并写入种子数据，无需手工执行 SQL
- 表结构变更直接修改 `server/Models/LayimModels.cs` 后删除旧库重启即可（演示环境方案）

## 2. 表关系总览

```
Users ────────┬──< FriendGroups ──< Friendships
   │          │        (一个用户多个分组)   (分组下的好友)
   │          │
   │          └──< GroupMembers >── ChatGroups
   │                  (多对多)
   └──< Messages (发送者外键，逻辑关联)
```

> 说明：用户ID、群ID 均为**字符串主键**（LayIM 前端约定）；Friendships 为单向两行存储（A 的好友列表里有 B、B 的好友列表里有 A 各一行）。

## 3. 表结构明细

### 3.1 Users — 聊天用户

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | string, PK | 用户ID，数字递增字符串（种子从 100001 起） |
| Username | string | 登录名/显示名，唯一（2-20 字符） |
| PasswordHash | string | PBKDF2(HMAC-SHA256) 哈希，Base64 |
| Salt | string | 密码盐，Base64 |
| Avatar | string | 头像 URL |
| Sign | string | 个性签名 |
| Status | string | `online` / `hide`（隐身） |
| CreatedAt | datetime | 创建时间（UTC 存储，接口输出时转为毫秒时间戳由前端本地化） |

### 3.2 FriendGroups — 好友分组

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int, PK, 自增 | 分组ID |
| GroupName | string | 分组名（如"我的好友"） |
| OwnerId | string, FK→Users.Id | 分组所属用户 |

### 3.3 Friendships — 好友关系

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int, PK, 自增 | |
| OwnerId | string | 好友列表的拥有者 |
| FriendId | string | 好友用户ID |
| FriendGroupId | int, FK→FriendGroups.Id | 该好友所在分组（拥有者视角） |

查询某用户好友列表：`Friendships.Where(f => f.OwnerId == uid)` 关联 Users 取好友资料。

### 3.4 ChatGroups — 群组

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | string, PK | 群ID（种子数据为 "101"、"102"） |
| GroupName | string | 群名称 |
| Avatar | string | 群头像 URL |
| OwnerId | string | 群主用户ID（逻辑关联，无强外键） |

### 3.5 GroupMembers — 群成员

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | long, PK, 自增 | |
| GroupId | string, FK→ChatGroups.Id | |
| UserId | string, FK→Users.Id | |

### 3.6 Messages — 聊天消息

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | long, PK, 自增 | |
| FromUserId | string | 发送者用户ID |
| ToType | string | `friend`（单聊）/ `group`（群聊） |
| ToId | string | 接收方：好友用户ID 或 群ID |
| Content | string | 消息内容（LayIM 语法：`face[x]` `img[url]` `file(url)[name]`） |
| CreatedAt | datetime | 发送时间（UTC 存储） |

查询单聊记录：`ToType='friend' AND ((FromUserId=A AND ToId=B) OR (FromUserId=B AND ToId=A))`
查询群聊记录：`ToType='group' AND ToId=群ID`

## 4. 各数据库连接配置

`server/appsettings.json`：

```json
"Database": {
  "Provider": "Sqlite",
  "Sqlite": "Data Source=layim.db",
  "SqlServer": "Server=localhost;Database=LayimChat;User Id=sa;Password=***;TrustServerCertificate=True;Encrypt=False",
  "MySql": "Server=localhost;Port=3306;Database=layimchat;User=root;Password=***;CharSet=utf8mb4"
}
```

也可用环境变量覆盖（优先级更高）：`Database__Provider`、`Database__SqlServer` 等。

| 数据库 | 库名 | 备注 |
|---|---|---|
| SQLite | `server/layim.db` 文件 | 零部署，适合开发/演示 |
| SQL Server | `LayimChat` | 2008 R2 需保留 `UseCompatibilityLevel(100)`（[Program.cs](../server/Program.cs)）；2016+ 可删除 |
| MySQL | `layimchat` | 驱动自动以 utf8mb4 建表 |

## 5. 种子数据

首次启动时写入：

- 用户：测试1~测试5（ID 100001~100005，密码均 `123456`），互为好友
- 群组：测试群组一（101）、测试群组二（102），全员入群
- 若干演示消息

库已存在则跳过种子，**不会**重复写入。

## 6. 运维备注

- 消息表无外键强约束（FromUserId/ToId 为逻辑关联），删除用户不会级联删消息，聊天记录完整保留。
- 时间统一 UTC 存储；SQLite 场景下前端显示已通过毫秒时间戳本地化（历史遗留数据若出现 -8 小时偏移，为旧版本本地时间入库，见 git 记录）。
- 数据备份：SQLite 直接备份 `layim.db` 文件；SQL Server/MySQL 用各自备份方案。`uploads/` 目录需随库一并备份。
