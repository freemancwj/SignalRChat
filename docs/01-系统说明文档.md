# CXIM 系统说明文档

## 1. 系统概述

CXIM 是基于 **LayIM 3.9.8** 前端 + **ASP.NET Core 8 + SignalR** 后端的网页即时聊天系统，支持单聊、群聊、消息持久化、历史记录、图片/文件（含视频）传输、在线状态、个性签名，并提供面向第三方系统的 **SSO 单点登录** 与 **服务端集成 API**。

## 2. 技术栈

| 层 | 技术 |
|---|---|
| 前端 | LayIM 3.9.8（layui 2.x）、原生 ES2017+ JS、SignalR JS Client 8.0（已本地化 `signalr/signalr.min.js`） |
| 后端 | ASP.NET Core 8（MVC + SignalR + Cookie 认证） |
| ORM | Entity Framework Core 8 |
| 数据库 | SQLite（默认）/ SQL Server（兼容 2008 R2，CompatibilityLevel=100）/ MySQL 8（utf8mb4，Pomelo 驱动）/ PostgreSQL（Npgsql 驱动） |
| 密码 | PBKDF2（HMAC-SHA256）加盐哈希 |

## 4. 核心流程

### 4.1 消息收发

```
发送方 LayIM sendMessage 事件
  → SignalR: ChatHub.SendMessage(toId, toType, content)
  → 服务端落库 Messages 表
  → 转发：
      friend → Clients.User(接收者ID)
      group  → Clients.OthersInGroup("group_群ID")
  → 接收方 layim.getMessage() 渲染
```

关键约定：**好友消息的 `id` = 发送者用户ID，群消息的 `id` = 群ID**（LayIM 以此匹配聊天窗口）。服务端、集成 API 均遵守该规则。

### 4.2 连接生命周期

- `OnConnectedAsync`：自动将该连接加入其所有群组（`group_{id}`），推送**离线消息**，向好友广播 `FriendStatus(online)`
- `RejoinGroups`：客户端断线重连后重新入组（前端 `reconnected` 事件触发）
- `OnDisconnectedAsync`：最后一个连接断开时记录 `Users.LastSeenAt` 并向好友广播 `FriendStatus(offline)`
- 多标签页/多设备通过内存连接数计数（`OnlineCounts`）判定"最后一个连接"

### 4.3 离线消息

- 依据 `Users.LastSeenAt`（送达水位）判定离线期间的消息：发给"我"的单聊 + "我"所在群的群消息，上限 200 条
- 补推时机：SignalR 连接建立后立即推送给该连接（`Clients.Caller`），前端 `ReceiveMessage` 处理会在聊天列表生成未读角标
- 水位推进：补推完成后、以及最后一个连接断开时各更新一次，保证同一批消息只补推一次
- 既有数据库升级：启动时自动检测并为 `Users` 表补充 `LastSeenAt` 列（四种数据库均支持），老用户回填为升级时间，避免收到全部历史消息

### 4.4 上传

- 聊天窗口"发送图片" → `POST /api/upload/image`（≤10MB，jpg/png/gif/bmp/webp）
- 聊天窗口"发送文件" → `POST /api/upload/file`（≤200MB，视频/音频/图片/文档/压缩包/html/js）
- 安全处理：`/uploads` 下的 `.html/.htm/.js/.svg` 强制 `Content-Disposition: attachment` 下载，防 XSS

### 4.5 历史消息

聊天窗口"聊天记录"弹窗（`dist/layim-assets/html/chatlog.html`）调用 `GET /api/layim/chatlog?id=&type=` 从数据库读取真实历史。

## 5. 前端页面接口一览（Cookie 认证）

| 接口 | 说明 |
|---|---|
| POST /api/auth/register | 注册（自动互加好友、入群） |
| POST /api/auth/login | 登录 |
| POST /api/auth/logout | 登出 |
| GET /api/auth/me | 当前登录用户 |
| GET /api/auth/sso?ticket= | 第三方单点登录（见集成文档） |
| GET /api/layim/init | LayIM 初始化数据（我的资料/好友分组/群） |
| GET /api/layim/members?id= | 群成员列表 |
| GET /api/layim/chatlog?id=&type= | 历史消息 |
| POST /api/layim/sign | 修改个性签名 |
| POST /api/layim/avatar | 更换头像（multipart 上传图片，≤2MB，jpg/png/gif/bmp/webp） |
| POST /api/upload/image /file | 上传 |
| ws(s)://…/chatHub | SignalR 长连接 |

第三方集成接口（ApiKey）见 [04-系统集成文档.md](04-系统集成文档.md)。
