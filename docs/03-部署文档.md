# CXIM 部署文档

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| 运行时 | .NET 8（开发用 SDK，生产服务器装 **ASP.NET Core Runtime 8.0+** 即可） |
| 数据库 | SQLite（自带）/ SQL Server 2008 R2+ / MySQL 5.7+/8.0 |
| 操作系统 | Windows / Linux / macOS 均可 |
| 浏览器 | 现代浏览器（需支持 WebSocket，SignalR 使用） |

## 2. 配置说明（server/appsettings.json）

```json
{
  "Urls": "http://localhost:5300",          // 监听地址；生产可改 "http://0.0.0.0:5300"
  "Database": {
    "Provider": "SqlServer",                // Sqlite / SqlServer / MySql
    "Sqlite": "Data Source=layim.db",
    "SqlServer": "Server=...;Database=LayimChat;User Id=sa;Password=***;...",
    "MySql": "Server=...;Port=3306;Database=layimchat;User=root;Password=***;CharSet=utf8mb4"
  },
  "Integration": {
    "ApiKey": "改成足够长的随机串",           // 第三方服务端 API 密钥
    "SsoSecret": "改成足够长的随机串"          // 第三方 SSO 签名密钥
  }
}
```

所有配置均可用环境变量覆盖（推荐生产环境使用，避免密钥入库）：

```
Database__Provider=SqlServer
Database__SqlServer=Server=...;...
Integration__ApiKey=...
Integration__SsoSecret=...
Urls=http://0.0.0.0:5300
```

## 3. 开发环境启动

```bash
dotnet run --project server/LayimChat.csproj
# 打开 http://localhost:5300 ，账号 测试1~测试5 / 123456
```

首次启动自动建库 + 种子数据。

## 4. 生产部署

### 4.1 发布

```bash
cd server
dotnet publish -c Release -o publish
```

### 4.2 前端静态资源

项目结构要求 `publish` 目录与前端目录保持如下关系（程序通过相对路径定位 `../` 即项目根）：

```
<部署根目录>/
├── index.html、layui/、dist/、signalr/、uploads/   # 前端静态资源
└── publish/                                        # 后端发布输出
    ├── LayimChat.dll、appsettings.json、...
```

> 即把整个"示例"目录拷到服务器，后端只取其中 `server/publish` 运行。`uploads/` 需给运行账号**写权限**。

### 4.3 Windows + IIS

1. 安装 [ASP.NET Core 8 Hosting Bundle](https://dotnet.microsoft.com/download/dotnet/8.0)（含 ANCM 模块）。
2. IIS 站点指向**部署根目录**（含 index.html 的目录），应用程序池 ".NET CLR 版本"选**无托管代码**。
3. 将 `publish/` 内容放到站点根下，或配置 `web.config` 的 `processPath` 指向 `dotnet` + `LayimChat.dll` 路径。
4. **必须启用 WebSocket 协议**（IIS → 服务器角色 → WebSocket Protocol），否则 SignalR 无法建立长连接（会降级轮询或失败）。

### 4.4 Windows 服务 / 直接运行

```bash
cd publish
dotnet LayimChat.dll --urls http://0.0.0.0:5300
```

注册为 Windows 服务可用 `sc create` 或 [NSSM](https://nssm.cc) 托管该命令。

### 4.5 Linux（systemd 示例）

```ini
# /etc/systemd/system/cxim.service
[Unit]
Description=CXIM Chat
After=network.target

[Service]
WorkingDirectory=/opt/cxim/publish
ExecStart=/usr/bin/dotnet /opt/cxim/publish/LayimChat.dll --urls http://0.0.0.0:5300
Restart=always
Environment=ASPNETCORE_ENVIRONMENT=Production
Environment=Database__Provider=MySql
Environment=Database__MySql=Server=127.0.0.1;Port=3306;Database=layimchat;User=root;Password=***;CharSet=utf8mb4
Environment=Integration__ApiKey=换成随机串
Environment=Integration__SsoSecret=换成随机串

[Install]
WantedBy=multi-user.target
```

### 4.6 反向代理（Nginx/IIS 前置）

SignalR 需要 WebSocket 透传，Nginx 关键配置：

```nginx
location / {
    proxy_pass http://127.0.0.1:5300;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;        # WebSocket
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    client_max_body_size 210m;                     # 匹配文件上传 200MB 限制
}
```

## 5. 数据库初始化与切换

- 切换数据库：修改 `Database:Provider`（或环境变量）后重启即可，新库自动建表 + 种子。
- 三个库之间数据**相互独立**，切换不会迁移旧数据。
- SQL Server 2008 R2：必须保留 `UseCompatibilityLevel(100)`（已在 Program.cs 内置）；SQL Server 2016+ 可删除该参数以获得更好查询性能。

## 6. 安全与运维清单

- [ ] 修改 `Integration:ApiKey` / `Integration:SsoSecret` 为随机长串（用环境变量注入）
- [ ] 修改种子账号密码（测试1~5 默认 123456），或清理演示数据
- [ ] 配置 HTTPS（SSO ticket、Cookie 均依赖传输安全）
- [ ] 防火墙放行监听端口；内网部署建议限制来源
- [ ] `uploads/` 目录纳入备份（与数据库一起）
- [ ] 日志：默认输出到控制台，生产可用 `Serilog`/文件日志扩展（按需）
- [ ] Data Protection 密钥：多实例/重启后保持 Cookie 有效，需配置持久密钥目录（`server/keys/`，单实例默认即可）

## 7. 健康检查与验证

```bash
# 服务存活（未登录返回 code:1 属正常）
curl http://<host>:5300/api/auth/me

# 登录冒烟
curl -X POST http://<host>:5300/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"测试1","password":"123456"}'
```

浏览器打开 `http://<host>:5300`，F12 控制台出现 `SignalR 已连接` 即长连接正常。
