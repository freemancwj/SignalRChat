# CXIM 即时通讯系统 —— 系统介绍与使用指南

> CXIM 是一套可独立部署、也可嵌入办公系统的 Web 即时通讯系统。
> 前端沿用 LayIM v3.9.8 的界面风格，后端为 ASP.NET Core 8 + SignalR，数据持久化到关系型数据库。
> 本文介绍系统的技术栈、数据库支持、功能清单与日常使用方法；接口对接细节见《05-办公系统集成指南》。

---

## 一、系统简介

CXIM 面向企业内部沟通场景，提供「通讯录 + 单聊 + 群聊 + 文件传输 + 语音/视频」的完整闭环。它有两种使用形态：

| 形态 | 说明 |
| --- | --- |
| 独立使用 | 独立部署为一个聊天站点，自带注册、登录、群组管理，用户可直接访问使用 |
| 集成使用 | 作为办公系统的一个模块：用户与部门数据由办公系统同步，页面右下角显示聊天图标，点击展开面板，免登录进入 |
| 网站客服 | 官网侧边栏放客服图标，访客点击后免登录生成临时账号（随机用户名），直接与固定客服一对一聊天，客服一对多同时接待 |

三种形态共用同一套代码与数据库，可同时启用。

## 二、技术架构

| 层次 | 采用的技术 |
| --- | --- |
| 前端界面 | LayIM v3.9.8（layui 2.x + jQuery），原生 HTML/CSS/JavaScript，无前端构建步骤 |
| 实时通信 | ASP.NET Core SignalR（WebSocket，自动降级 SSE / 长轮询），浏览器端使用本地化 `signalr.min.js` |
| 后端服务 | ASP.NET Core 8（Web API + MVC 控制器），Kestrel 自托管 |
| 数据访问 | Entity Framework Core 8（Code First，`EnsureCreated` 自动建库建表） |
| 身份认证 | Cookie 认证（`.layim.auth`，HttpOnly、SameSite 可配），密码 PBKDF2 加盐哈希存储 |
| 文件上传 | 本地磁盘 `uploads/` 目录，接口返回 LayIM 约定的 `{code,data:{src,name}}` |
| 音视频 | WebRTC（视频通话）+ MediaRecorder（语音消息）+ getDisplayMedia / html2canvas（框选截图） |
| 部署方式 | `dotnet run` / `dotnet publish` 后由 Kestrel 直接提供服务，也可放在 Nginx / IIS 反向代理之后 |

典型请求链路：

```
浏览器（LayIM 界面）
   ├─ HTTP  → /api/layim/*、/api/upload/*、/api/auth/*   （业务接口，Cookie 认证）
   └─ WebSocket → /chathub                               （消息实时收发、在线状态、通话信令）
                       ↓
                ASP.NET Core 8（控制器 + ChatHub）
                       ↓
                EF Core 8 → 数据库（SQLite / SQL Server / MySQL / PostgreSQL）
```

## 三、支持的数据库

通过 `server/appsettings.json` 的 `Database:Provider` 一行切换，无需改代码：

| Provider 值 | 数据库 | 连接串配置键 | 适用场景 |
| --- | --- | --- | --- |
| `Sqlite` | SQLite（默认） | `Database:Sqlite` | 单机部署、演示、轻量使用；数据文件 `server/layim.db` |
| `SqlServer` | Microsoft SQL Server | `Database:SqlServer` | 企业内已有 SQL Server；已适配兼容级别 100（SQL Server 2008 R2 可用） |
| `MySql` | MySQL / MariaDB | `Database:MySql` | 企业内已有 MySQL；连接串需 `CharSet=utf8mb4` |
| `PostgreSql` | PostgreSQL | `Database:PostgreSql` | 企业内已有 PostgreSQL |

也可以不改文件，用环境变量覆盖：`Database__Provider=MySql`。

```json
"Database": {
  "Provider": "Sqlite",
  "Sqlite": "Data Source=layim.db",
  "SqlServer": "Server=localhost;Database=LayimChat;User Id=sa;Password=***;TrustServerCertificate=True;Encrypt=False",
  "MySql": "Server=localhost;Port=3306;Database=layimchat;User=root;Password=***;CharSet=utf8mb4",
  "PostgreSql": "Host=localhost;Port=5432;Database=layimchat;Username=postgres;Password=***"
}
```

说明：

- 首次启动自动建库建表并写入演示数据（用户、群组、历史消息）；
- 已有数据库升级时，启动过程会自动补齐新增字段（如 `LastSeenAt` 离线水位、`IsAdmin` 管理员标记），无需手工执行 SQL；
- 切换数据库等于换一份数据，各库之间不会自动迁移。

## 四、系统特点

1. **双模式**：独立使用与办公系统集成共用一套服务，不维护两份代码。
2. **真实后端**：消息、好友/部门关系、群成员、聊天记录全部落库，不是前端模拟；多标签页、多设备之间实时同步。
3. **四种数据库可切**：一套代码适配 SQLite / SQL Server / MySQL / PostgreSQL，适合不同企业的既有环境。
4. **零构建前端**：直接由后端托管静态页面，改样式/改脚本后刷新即生效，部署简单。
5. **弱网与掉线友好**：SignalR 自动重连；离线期间的消息在下次上线时补推（水位机制，最多 200 条，不重复推送）。
6. **桌面 + 手机自适应**：窄屏自动切换为全屏面板与全屏聊天窗口，可当作移动端网页使用。
7. **权限克制而实用**：普通用户可注册/加群/退群/改昵称密码/换头像；只有超级管理员可建群、改名、解散群、移除成员。
8. **可集成**：SSO 单点登录、ApiKey 数据同步接口、右下角聊天挂件（`embed.js`），接入改动仅需一段脚本。
9. **安全细节**：密码加盐哈希；上传目录中的 `.html/.htm/.js/.svg` 强制下载，避免被当作网页执行；会话 Cookie 关闭浏览器即失效。

## 五、功能清单

### 5.1 账号

- 注册：用户名 + 密码，可选择所属部门（群组），也可选「暂不加入群组」
- 登录 / 退出登录（退出按钮在面板头部，橙色实心，皮肤切换下均可见）
- 关闭浏览器即退出（会话级 Cookie），再次打开站点需重新登录
- 登录后点击面板头部**用户名**可修改用户名与登录密码（新密码留空表示只改用户名）
- 点击面板头部**头像**可更换自定义头像，或恢复默认头像
- 头像未设置时统一显示默认头像，不会出现破图

### 5.2 通讯录与好友

- 左侧「好友」按部门（群组）分组展示成员，展开后即该部门全部成员
- 在线状态：好友名称下方显示绿点「在线」/ 灰点「不在线」，实时随上下线切换
- 底部搜索框可搜索用户与群组（同一用户属于多个部门时不会重复显示）

### 5.3 聊天

- 单聊：点击好友即可打开聊天窗口
- 群聊：点击群组向整个群广播消息，群内所有成员实时收到
- 消息类型：文本、表情、图片、文件（文档 / 压缩包 / 音视频等）、语音消息、截图、视频通话
- 消息时间、发送者头像、气泡样式与 LayIM 原生风格一致
- 聊天记录：聊天窗口右上角「聊天记录」按钮，支持按关键字搜索，最多返回 300 条
- 离线消息：对方不在线时消息先入库，其下次登录后自动补推

### 5.4 富媒体工具（聊天输入框上方工具栏）

| 工具 | 说明 |
| --- | --- |
| 表情 / 图片 / 文件 | 直接插入或上传，图片支持粘贴、拖拽 |
| 代码 | 插入代码块 |
| 截图 | 剪刀图标，点击后屏幕变暗，鼠标框选区域截图并发送（非整页快照） |
| 语音消息 | 点击开始录音（最长 30 分钟，可随时停止），停止后上传并发送；录音过程中实时识别文字，发送后语音气泡下方附带「【语音转写】…」文字，接收方与聊天记录同样可见 |
| 视频通话 | 1 对 1 呼叫；接通后显示本地小窗与远端画面，支持挂断 / 关闭，弹窗可正常关闭 |

> 截图、语音、视频通话需要浏览器授权摄像头/麦克风/屏幕共享；视频通话与屏幕共享要求 HTTPS 或 localhost 环境。

### 5.5 群组与成员

- 所有登录用户：底部工具栏可「加群 / 退群」；加入后左侧群组与通讯录即时更新，无需刷新；退群时对应聊天窗口自动关闭
- 超级管理员（账号 `admin`）：
  - 建群（自动加入新群）
  - 修改群名称（在线成员界面实时同步，含左侧群列表、通讯录部门名、聊天窗口标题）
  - 解散群（成员关系与聊天记录一并删除，在线成员界面即时移除）
  - 移除群成员（被移除者收到提示，界面即时移除该群）

### 5.6 界面

- 内置 5 套皮肤可选（图片来源 `dist/layim-assets/skin/`，默认 `5.jpg`）
- 主面板可拖动、可最小化
- 移动端响应式：≤768px 时主面板铺满屏幕、聊天窗口全屏、输入区贴底、弹层不超出屏幕
- 内嵌模式（`?embed=1`）：面板铺满 iframe，供办公系统右下角挂件使用

### 5.7 集成能力

- SSO 单点登录（HMAC-SHA256 票据，5 分钟有效，自动开户）
- 数据同步接口（用户、群组、成员，ApiKey 认证）
- 消息推送接口（业务系统向用户或群组发送系统通知）
- 右下角聊天挂件 `embed.js`（图标 + 面板 + 未读角标 + postMessage 事件）

### 5.8 网站客服（访客聊天）

- 官网侧边栏客服图标 → 弹出聊天面板（演示页 `website.html`，`iframe` 加载 `index.html?embed=1&guest=1`）
- 访客免登录：自动创建临时账号，用户名随机生成（`访客` + 8 位随机字符），关闭浏览器即失效
- 客服使用**独立的登录页 `kefu.html`**（无注册入口，非客服账号会被拒绝）和**客服工作台**（无群组/部门，联系人列表只有「访客」）
- 固定客服账号 `kefu`（ID 999998）对访客恒显示在线，一对多同时接待；访客之间互相隔离、互不可见
- 客服不在电脑前时，访客消息按离线消息落库，客服上线后自动补推，不漏消息
- 访客模式自动精简界面（隐藏退出、工具栏、群组等），只保留与客服的会话窗口

## 六、快速开始

### 6.1 运行环境

- .NET 8 SDK（开发／运行）
- 浏览器：Chrome / Edge / Firefox 等现代浏览器（视频通话需摄像头、麦克风）

### 6.2 启动

```bash
cd 示例
dotnet run --project server/LayimChat.csproj
```

浏览器访问 `http://localhost:5300`。端口在 `server/appsettings.json` 的 `Urls` 中配置。

### 6.3 默认账号

| 账号 | 密码 | 说明 |
| --- | --- | --- |
| `测试1` ~ `测试5` | `123456` | 演示用户，互为好友，已加入演示群组 |
| `admin` | `cwjaixy1314` | 超级管理员，可建群 / 改群名 / 解散群 / 移除成员 |
| `kefu` | `kefu@123456` | 网站客服（固定接待账号），登录后接待访客；访客账号由系统自动生成，无需密码 |

> 建议首次部署后立即修改 admin 密码（点击面板头部用户名即可修改），并更换 `Integration:ApiKey`、`Integration:SsoSecret`。

### 6.4 数据库配置

见第三节。修改 `Database:Provider` 后重启服务即可切换；SQLite 无需准备，其他数据库需先保证账号可建库。

### 6.5 目录结构（主要部分）

```
示例/
├─ index.html                 聊天主页面（布局、全部前端交互）
├─ embed.js                   办公系统内嵌挂件（右下角图标）

   ├─ Program.cs              启动、认证、静态文件、EF Core 配置
   ├─ Controllers/            Auth / Layim / Upload / Admin / Integration
   ├─ Hubs/ChatHub.cs         SignalR：消息、状态、加群组、通话信令、离线补推
   ├─ Data/                   DbContext、建库与种子数据、schema 补丁
   ├─ Models/                 用户、好友、群组、消息等实体
   └─ Services/               密码哈希、用户开通、头像兜底、ApiKey 校验
```

## 七、使用方法

### 7.1 登录与注册

1. 打开站点，弹出「CXIM 登录」窗口；
2. 输入用户名与密码登录；首次使用点「注册」，填写用户名、密码，并选择所属部门（可选择「暂不加入群组」）；
3. 注册成功后自动与现有用户互加好友，登录后即可聊天；
4. 面板头部右侧橙色「退出」按钮可退出登录。

### 7.2 主面板

- 头部：我的头像（点击更换）→ 用户名（点击修改用户名/密码）→ 退出按钮
- 左侧：好友（按部门分组）、群组、最近聊天
- 底部：搜索框；工具栏含「加群 / 退群」；管理员额外看到「群组管理」

### 7.3 发送消息

1. 点击好友或群组打开聊天窗口；
2. 输入文字后按 `Enter` 发送，`Ctrl+Enter` 换行；
3. 点击工具栏图标可发送表情、图片、文件、截图、语音；
4. 点击「视频通话」发起 1 对 1 通话，对方接听后即可通话，任一方的挂断按钮都会关闭通话窗口。

### 7.4 截图

点击工具栏剪刀图标 → 屏幕变暗 → 按住鼠标左键框选区域 → 松开后自动截图并发送到当前聊天窗口；按 `Esc` 可取消。

### 7.5 语音消息（含语音转文字）

1. 点击工具栏麦克风图标开始录音，弹窗显示录音时长与实时识别出的文字；
2. 录音时长上限为 **30 分钟**（原 60 秒限制已取消，可随时点击「停止并发送」；如需调整，修改 `index.html` 中的 `VOICE_MAX_SECONDS`）；
3. 停止并发送后，语音气泡下方会附带「【语音转写】…」文字，随消息一并入库，接收方与聊天记录中都能看到；
4. 语音转文字使用浏览器自带的 Web Speech API（Chrome / Edge 支持中文）。若浏览器不支持或无法访问识别服务（例如内网无法访问 Google 语音服务），录音弹窗会提示「语音转文字不可用，本次仅发送语音」，语音消息本身仍可正常发送与播放。

### 7.6 聊天记录

在聊天窗口右上角点击「聊天记录」，弹窗展示历史消息；顶部搜索框可输入关键字过滤，回车或点击搜索执行。

### 7.7 修改用户名 / 密码 / 头像

- 用户名：点击面板头部用户名 → 修改用户名（2–20 字符，不可与别人重名）→ 可选填新密码与确认密码 → 保存；
- 头像：点击面板头部自己的头像 → 选择图片（≤2MB）→ 上传成功后面板刷新；也可「恢复默认头像」。

### 7.8 加群 / 退群

点击主面板底部工具栏的「加群 / 退群」→ 在弹窗中选择要加入的群（或点击已加入群后的「退出」）→ 列表与聊天窗口即时更新，无需重新登录。

### 7.9 管理员操作

用 `admin` 登录后，底部工具栏出现「群组管理」：

| 操作 | 步骤 |
| --- | --- |
| 建群 | 「群组管理」→ 输入群名称 → 新建 |
| 修改群名 | 群条目右侧「改名」→ 输入新名称 → 保存（在线成员界面同步更新） |
| 解散群 | 群条目右侧「解散」→ 确认（成员关系与聊天记录一并删除） |
| 移除成员 | 「成员」→ 在成员列表中移除指定用户 |

### 7.10 手机访问

用手机浏览器访问 `http://<服务器IP>:5300`（需在同一网络），界面自动变为全屏布局：主面板铺满、聊天窗口全屏、输入区贴底。若需 https（视频通话/录音在部分浏览器要求），请在前面加反向代理并配置证书。

### 7.11 网站客服

**客服人员**：用客服专用入口 `http://<聊天系统>/kefu.html` 登录（该页只有登录表单，没有注册入口；用工号等非客服账号登录会被拒绝并撤销登录）。登录后进入客服工作台：没有「群组」选项卡、没有群组列表、底部没有加群/退群按钮，联系人列表只有一个「访客」分组，按最近消息时间排序，可直接回复任意访客；新访客进入网站时会实时出现在列表中。退出登录会回到 `kefu.html`。

**访客接入**（两种方式）：

1. **演示**：直接访问 `http://localhost:5300/website.html`，点击右侧蓝色「客服」图标体验完整流程；
2. **接入自己的官网**：参考 `website.html` 的实现，在官网页面放入客服图标，点击时弹出 iframe 加载 `http://<聊天系统>/index.html?embed=1&guest=1` 即可。访客进入后自动获得随机用户名（`访客xxxxxxxx`），直接与客服对话；面板会显示客服回复的未读角标（同站点部署时无需任何配置，独立部署时把 `website.html` 中的 `CHAT_BASE` 改为聊天系统地址）。

> 说明：访客账号是临时用户，只与客服互为好友、不加入任何群组，不会出现在企业用户的通讯录中；聊天记录会正常保存，可在「聊天记录」中查询。

## 八、数据与文件说明

| 路径 | 内容 | 说明 |
| --- | --- | --- |
| `server/layim.db` | SQLite 数据文件 | 仅 `Provider=Sqlite` 时产生 |
| `server/keys/` | DataProtection 密钥 | 用于 Cookie 加密，删除会导致所有人登录态失效 |
| `uploads/` | 上传的图片、文件、语音、头像 | 建议纳入备份；`.html/.htm/.js/.svg` 强制下载 |
| `server/appsettings.json` | 数据库、端口、集成密钥 | 含敏感信息，勿公开仓库 |

备份建议：数据库 + `uploads/` 目录 + `server/keys/` 三者一起备份。

---

## 九、安全与运维建议

1. 修改默认管理员密码；删除或禁用不需要的演示账号；
2. 更换 `Integration:ApiKey`、`Integration:SsoSecret` 为强随机值；
3. 生产环境启用 HTTPS（视频通话、录音、跨站内嵌都依赖安全上下文）；
4. 跨站点 iframe 内嵌时，把 `Cookie:SameSite` 设为 `None` 并启用 HTTPS；
5. 上传目录不要配置为可执行脚本；建议限制单文件大小与类型（系统已内置 200MB 上限与白名单）；
6. 定期备份数据库与 `uploads/`。
